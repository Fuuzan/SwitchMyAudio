# Switch My Audio 0.7.0 beta

A lightweight Windows utility for switching playback devices and microphones.

## Features

- Select speakers, headphones and microphones independently.
- Assign global shortcuts to devices or cycle through selected sources.
- Rename devices and arrange them with drag-and-drop or arrow buttons.
- Use a compact, resizable window that stays on top, with playback and microphones side by side.
- Choose light, dark or System theme.
- Enable optional sound activity meters and automatic headphone switching.
- Keep shortcuts active while the app is in the system tray.

## Default settings

Start with Windows is on. Theme follows Windows. Level meters and automatic headphone switching are off. Existing preferences are kept when updating.

## Requirements and limitations

Requires Windows 10/11 on Intel/AMD and .NET Framework 4.8 or later. ARM64 hardware is untested. Automatic switching depends on connection information supplied by Windows; some wireless receivers remain connected while the headset is off.

Downloads are unsigned, so Windows may show an unknown-publisher warning. Download from this project's Releases page and check the included SHA-256 checksums.
